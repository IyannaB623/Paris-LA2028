# Reproducible analysis

Run `python3 final_analysis/run_analysis.py`, then `python3 final_analysis/analyze_revenue.py`, then `python3 build_dashboard.py` from the project root (or run each script by absolute path). The analysis script reads `past_rates.csv` and writes into `final_analysis/`. It calculates the native-price 99th percentile once across the pooled valid four-month sample (21,172 rows), then applies the same €1,090.58 cutoff in 2023 and 2024. The primary cleaned CSV has 20,960 rows and 8,127 listings; `full_valid_analysis.csv` retains the full sample for sensitivity comparisons. Environment: Python 3.11.2, pandas 3.0.6, numpy 2.4.6. `statsmodels` and `scipy` are unavailable in the supplied environment, so OLS and listing-clustered sandwich standard errors are computed directly with NumPy; inference uses Student t with listing-cluster degrees of freedom.

Outputs include primary and full-sample descriptive/regression tables, period counts, slope contrasts, balanced-panel sensitivity results, data-quality JSON, the full-price histogram with cutoff, trimmed-sample charts, notebook, and team summary. The revenue script saves trimmed primary comparisons and clearly labeled supplementary full-sample comparisons. Price and revenue use native-currency fields as EUR under explicit assumptions. Dashboard charts are embedded in `analysis_output/dashboard.html`.
