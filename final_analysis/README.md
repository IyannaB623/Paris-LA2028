# Reproducible analysis

Run `python3 final_analysis/run_analysis.py`, then `python3 final_analysis/analyze_revenue.py`, then `python3 build_dashboard.py` from the project root (or run each script by absolute path). The first script reads `past_rates.csv`; the revenue script reads the prepared analysis CSV; both write only into `final_analysis/`. The final command rebuilds `analysis_output/dashboard.html`. Environment: Python 3.11.2, pandas 3.0.6, numpy 2.4.6. `statsmodels` and `scipy` are unavailable in the supplied environment, so OLS and listing-clustered sandwich standard errors are computed directly with NumPy; p-values and t confidence intervals use the Student t distribution with listing-cluster degrees of freedom, calculated by the included incomplete-beta routine.

Files include `cleaned_analysis.csv`, `variable_dictionary.csv`, descriptive and regression CSV tables, sensitivity table, data-quality JSON, analysis PNGs, and `team_summary.md`. The supporting revenue script adds `revenue_comparison.csv`, `revenue_data_quality.json`, `revenue_comparison.png`, `revenue_presentation_paragraph.md`, and `revenue_method_notes.md`. Analysis sample: 21,172 rows, 8,179 listings. Main models use the identical complete valid sample. Price and revenue use native-currency fields as EUR under explicit assumptions. Sensitivity specifications re-estimate Model 3.
